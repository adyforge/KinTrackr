## Features

- ⚔️ Automatic kill tracking
- 📜 Scroll tracking
- 🪙 Gold tracking
- 🪨 Resource tracking (Stone, Coal, Wood, Iron, Silver, Cacti, Fish, etc.)
- 👑 Boss tracking
- 📊 Session, daily and lifetime statistics
- 🌍 Automatic zone detection
- 🖱️ Draggable and resizable overlay
- 💾 All statistics are stored locally
- 🔒 No analytics, no telemetry, no remote servers

## Installation

### Chrome Web Store

Coming soon.

### Manual Installation (Developer Mode)

1. Download the file from [![Latest Release](https://img.shields.io/github/v/release/adyforge/KinTrackr?label=Latest%20Release)](https://github.com/AdyTech/KinTrackr/releases/latest).
2. Open **Google Chrome** and navigate to `chrome://extensions/` (or the extension screen for your browser).
3. Enable **Developer mode** using the toggle in the top-right corner.
4. Click **Load unpacked**.
5. Select the KinTrackr extension folder.
6. Launch **Kintara** in your browser.
7. The KinTrackr overlay will automatically appear once you enter the game.

> **Note:** Extract it before selecting the folder in Step 5.

---

## Usage

### Opening the Overlay

If the KinTrackr overlay is hidden, you can make it visible again by:

- Pressing **Alt + K**
- Clicking the **K** button in the top-right corner of the game

---

### Overlay Controls

The overlay includes several built-in controls:

- **↻ Reset** – Resets the current session statistics.
- **⏻ Toggle** – Enables or disables tracking.
- **✕ Hide** – Hides the overlay without disabling the tracker.

---

### Context Menu

Right-click anywhere on the overlay to open the context menu, where you can:

- Show or hide individual counters.
- Reset statistics for the current area.
- Reset all tracked statistics.

---

### Overlay Customization

- Drag the title bar to move the overlay.
- Drag the bottom-right corner to resize it.
- Double-click the resize handle to restore the default size.
